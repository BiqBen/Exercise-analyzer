# Exercise-analyzer

The **Exercise Analyzer** is a Python application that automatically analyzes push-ups and squats from video recordings. Using **MediaPipe Pose** and **OpenCV**, it detects body landmarks, identifies individual repetitions, and evaluates relevant performance metrics such as range of motion, joint angles, symmetry, body posture, and movement speed. The results are presented alongside the analyzed video in a user-friendly interface. Its modular architecture allows the prototype to be extended with additional exercises and evaluation criteria.
